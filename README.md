# 🚀 Anurag.codes — Developer Portfolio

A modern, responsive, and performance-focused developer portfolio website built to showcase software development projects, technical skills, and experience.

🔗 **Live Demo:** [https://anurag-codes-taupe.vercel.app/](https://anurag-codes-taupe.vercel.app/)

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, Modern JavaScript (ES6+)
- **Styling:** Tailwind CSS (Responsive & Utility-First)
- **Icons:** Font Awesome & Lucide Icons
- **Contact Integration:** Web3Forms API
- **Deployment & Hosting:** Vercel

---

## ✨ Features

- **Responsive Design:** Fully optimized across mobile, tablet, and desktop viewports.
- **Interactive UI:** Dynamic typing effect, smooth scrolling, and polished hover states.
- **Live Resume Integration:** Direct access to up-to-date CV.
- **Privacy & Terms Pages:** Dedicated standalone policy documents for independent operation.
- **Working Contact Form:** Direct email delivery via secure form endpoint.
